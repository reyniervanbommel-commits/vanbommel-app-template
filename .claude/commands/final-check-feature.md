# /final-check-feature

Voer de final check uit op de huidige git-diff (ná feature of bugfix).

1. Lees en volg `.claude/skills/final-check-feature/SKILL.md` (of `.cursor/skills/final-check-feature/SKILL.md`).
2. Roep bestaande skills aan (`ui-design-review`, `perf-review`, `security-review`, `browser-feature-test`, `project-cleanup`) — niet nadoen.
3. Geen `perf-pipeline`. Snelheid = `perf-review`.
4. Kort rapport; blockers eerst fixen.
